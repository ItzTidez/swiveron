# Swiveron

## Summary

Swiveron is a free app, currently windows only, made to simplify your workflow. It stays in the tray so its always active. It adds profiles which can be activated manually with a button in the UI itself or via keybind.

## Features

There are currently only a few features but they are:
 - Opening and closing apps
 - Opening web links
 - Changing the audio input and output device
 - Changing the color of your rgb devices (via external software called OpenRGB)
 - Quiet mode - disables notifications

## Settings

In the settings window you can change the general settings about the app which currently are:
 - Start with windows (enabled by default)
 - Start minimized to tray (disabled by default)
